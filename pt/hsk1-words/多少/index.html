多少

duōshao

quanto; quantos

Tipo: PronomesHSK 1
Origem do caractere

多 (muito) + 少 (pouco). Juntar os dois extremos serve para perguntar uma quantidade exata sem supor se é grande ou pequena.

Sabia que...?

É mais formal que 几 (jǐ). Usa-se para quantidades que se espera serem maiores que dez. '多少钱' é a frase estrela para perguntar o preço.
